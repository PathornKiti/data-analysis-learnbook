## Learning goals
* Use variables, numbers, strings, lists, dictionaries
* Control flow with `if` and `for`; write and call functions
* Use list comprehensions
* Read an error message and fix the problem
* See Σ as a loop and *f(x)* as a function

## Common pitfalls
* Off-by-one: `range(3)` is 0, 1, 2 · slices exclude the end · list indexes start at 0
* `=` assigns, `==` compares
* Indentation matters; use 4 spaces
* Forgetting `return` (the function gives back `None`)
