# Module 2: Project kickoff

**Time:** ~1 week (3–5 h) · **Prerequisite:** Module 1

## Learning goals
* Distinguish describe / compare / relate / predict questions
* Turn a vague interest into a specific, measurable question
* Run a feasibility check on a candidate dataset (columns, size, missingness, licence)
* Write a project proposal and a data card

## Files
| file | purpose |
|---|---|
| `lesson.ipynb` | question types, sharpening questions, a worked feasibility check |
| `exercises.ipynb` | question labelling, feasibility in code, free-writing |
| [`../../projects/tracks.md`](../../projects/tracks.md) | interest tracks, starter questions, dataset sources |
| [`../../projects/templates/PROPOSAL.md`](../../projects/templates/PROPOSAL.md) | proposal template |
| [`../../projects/templates/DATA_CARD.md`](../../projects/templates/DATA_CARD.md) | data card template |

## 🎯 Project checkpoint: **proposal + data card**
1. Choose a topic and write three candidate questions.
2. Find **two** possible datasets and run the feasibility check on both.
3. Fill in `PROPOSAL.md` and a `DATA_CARD.md` for your preferred dataset.

Commit them in your own project repository (see `projects/template/`) so they live with your code.

## Tips
* Pick something you'd happily talk about for an hour. Motivation beats perfection.
* Prefer a dataset with **at least a few hundred rows** and **at least 5 columns**, with a mix of numbers and categories.
* If the data seems *too* tidy, check whether it's been cleaned for you; real projects will need cleaning (Module 5).
* Always check the licence: can you use and share it?
