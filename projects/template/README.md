# myproject: project template

A ready-to-run skeleton for your course project. It works out of the box with a sample dataset so you can see the
shape of a finished project, then you swap in your own data and questions.

## Make it yours
1. **Copy this folder out of the course repo** to a new location (ideally a new Git repository): `cp -r projects/template ~/my-project`
2. **Rename the package:** rename `src/myproject/` to a name you like (lowercase, no spaces), then update the `name` in
   `pyproject.toml` and the `from myproject...` imports in `run_analysis.py` and `tests/`.
3. Replace `data/raw/sample_students.csv` with your data, and fill in a data card (`../templates/DATA_CARD.md`).
4. Grow the modules as the course progresses (cleaning in Module 5, plots in Module 6, analysis in Module 8…).

## Run it
```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt                        # also installs this package in editable mode
python run_analysis.py                                 # reproduces the analysis
pytest                                                 # runs the tests
```

## Layout
```
run_analysis.py          one command reproduces everything
src/myproject/
    load.py              read raw data (never modifies it)
    clean.py             cleaning functions
    features.py          derived columns
    analysis.py          statistics: group summaries, CIs, bootstrap, permutation test, effect size
    plots.py             reusable chart functions
tests/                   pytest checks for the trickiest functions
notebooks/
    01_explore.ipynb     messy exploration is welcome here
    02_report.ipynb      the clean story; imports its logic from src/
data/raw/                original data (read-only!)
data/processed/          generated by the code (git-ignored)
reports/figures/         generated charts (git-ignored)
```

## Why this structure?
* **Notebooks are for thinking and telling the story.** Reusable logic lives in `.py` files so you can test it and reuse it.
* **Raw data never changes**, so you can always start over.
* **One entry point** means a stranger (or you in six months) can reproduce the result.
